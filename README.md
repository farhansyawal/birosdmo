## 📌 Tentang Proyek

Aplikasi berbasis web ini dikembangkan untuk mengintegrasikan dan memigrasikan berbagai layanan internal **Biro Sumber Daya Manusia dan Organisasi (BSDMO) KLH/BPLH** dari Google Sites ke dalam satu platform terpusat, aman, dan mudah dikelola.

### ✨ Fitur Utama
- 🔐 **Autentikasi & Manajemen Peran:** Sistem login aman dengan hak akses berbasis role (Admin, Staf, Pegawai).
- 👥 **Manajemen Data Pengguna & Pegawai:** Pengelolaan data akun dan informasi kepegawaian secara terstruktur.
- 📂 **Portal Layanan Kepegawaian:** Layanan pengajuan dan administrasi SDM secara digital.
- 📊 **Dashboard Interaktif:** Ringkasan statistik dan navigasi cepat untuk memantau aktivitas operasional.
